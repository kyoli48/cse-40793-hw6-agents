# Pricing team style guide
Applies to Python files. Findings must cite these IDs.
## S001 No trailing whitespace
Remove spaces and tabs at line ends.
## S002 Maximum line length
Keep source lines at most 88 characters long.
## S003 Function names
Use snake_case for function names.
## S004 Public function documentation
Every public function must have a docstring.
## S005 Monetary units in documentation
Docstrings for functions calculating money must explicitly state input and output
currency units, including whether values are dollars or cents.
